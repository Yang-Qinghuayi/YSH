# 原生设备发布门槛

当前全部设备项均为 **待验证**，不是已通过的测试报告。填写日期、设备/OS、构建版本、样书、结果和问题链接；不要只打一个“支持 Readium”勾。

## 构建门槛

- [ ] Node 24 `npm ci`、`npm run check`、双平台 bundle。
- [ ] Android Gradle Debug/Release 成功，Nitro/View 可装载。
- [ ] macOS CocoaPods + iOS Simulator Debug/Release 成功。
- [ ] iPhone、iPad、Android 手机、Android 平板各至少一台真机。
- [ ] 使用 Release 构建飞行模式冷启动，不依赖 Metro/CDN/首次字体下载。

## 数据与生命周期

- [ ] 文件提供器/Files 多选、取消、单个失败不影响其他；导入报告可读。
- [ ] 重复导入保留位置/批注；丢失应用副本后重导入可修复。
- [ ] 原文件移动/删除后仍可读；清缓存不丢书。
- [ ] 强杀、退后台、系统回收、重启后书库与位置一致。
- [ ] 低存储/拒绝访问/损坏文件导入无半条索引，孤儿文件重启清理。
- [ ] 删除只作用于应用副本；书签/高亮/笔记级联清理。
- [ ] 搜索取消/失败/分页/重复点击、结果跳转，退出后无旧结果污染。
- [ ] 笔记创建/修改/删除、高亮颜色、重开恢复、旋转不丢草稿。

## 响应式和主题

- [ ] 390/600/840/1024+ 可用宽度，Android 分屏、iPad Split View。
- [ ] 旋转和跨断点不重开书、不丢当前位置；面板变侧栏，无正文遮挡。
- [ ] 4 个种子 × light/dark/system，重启恢复，自定义非法值提示。
- [ ] Paper 弹层、NativeWind 自定义布局、新章节正文同步；PDF 白色页面不冒充深色反转。
- [ ] 双页/双列按格式和有效宽度启用；正文不无限拉伸。
- [ ] 软键盘、动态字体、VoiceOver/TalkBack、触摸/指针/外接键盘基本操作。

## 安全与性能

- [ ] LCP/DRM 明确拒绝，没有许可证或解密流程。
- [ ] 脚本、外链、路径穿越、实体、超大/压缩炸弹、编码绕过样本测试与原生沙箱审计。
- [ ] 原生引擎对 EPUB 外链/资源与 PDF 主动内容的实际处理经过验证；JS 预检不是最终防线。
- [ ] 小书、长章、大图、多批注、大 PDF 记录导入/开书时间、翻页延迟、搜索耗时、峰值内存。
- [ ] 低端设备连续读 30 分钟，无持续内存增长；明确可接受的文件限额与性能门槛。

完成这些门槛后，再把 README 从“首版实现、待设备验收”改为实际经过验证的平台支持声明。
